# Potret Wilayah - Public Demo

Urban-Rural Village Classification and
Interactive Business Intelligence.

## Data

All data and regions are synthetic and fictional.

No PODES microdata, official BPS statistics,
institutional logos, BIG boundaries, or private
research results are included.

## Features

- Regional filtering
- Urban and rural filtering
- Dynamic summary indicators
- Composition charts
- Responsive layout

## Run locally

    pip install -r requirements.txt
    streamlit run app.py

## Streamlit Community Cloud

- Branch: main
- Entrypoint: app.py

This public demonstration is separate from
the private research application.
